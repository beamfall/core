# Beamfall logo

The approved identity is the static Cut Beam mark with the BEAMFALL wordmark.
Canonical vectors and exports live in `beamfall-design-system/assets/brand/cut-beam/`;
`beamfall-design-system/assets/brand/beamfall-logo-mark.svg` is the primary mark.
The operator approved this identity and its rollout on 2026-09-28.

Use `beamfall-mark.svg` or `beamfall-logo.png` for marks and avatars, the horizontal
lockups for brand signatures, and the flat or monochrome mark for small icons.
Preserve the geometry and aspect ratio. The depth and cut-edge highlight are static;
there is no sweep animation. Adaptive and maskable icons need safe-area padding;
Apple app icons need an opaque background. Use an empty image alt beside visible
Beamfall text; otherwise use `Beamfall`.
