CORE-0022 / HLS-ENCODE-AHEAD-PACING-1
macOS real-media verification, 2026-11-19

The opt-in playback test uses the production Sessions manager and FFmpeg
runner. It transcodes a local 1080p HEVC source through VideoToolbox to
1080p H.264. A headless FFmpeg decoder plays the initialization segment
and numbered CMAF fragments. It requests one fragment every four seconds
for 60 seconds, then seeks by requesting the fragment at 80 seconds.

At each stopped observation, the test checks the number of completed
regular fragments beyond the playhead in both the published cache and the
encoder directory. The unopened segment gate is a FIFO. The test uses ps
to verify the same PID at the initial stop, after 60 seconds, during the
seek, and at the next stop.

Commands from the repository worktree:

  export GOCACHE=/tmp/codex-gocache GOWORK=off
  export CORE0022_MEDIA="$HOME/Movies/C0037.mp4" CORE0022_DURATION=264
  sw_vers
  uname -m
  ffmpeg -version | head -1
  go test ./internal/playback -run '^TestPacingMacOSReceipt$' -count=1 -v

To reproduce with another file, set CORE0022_MEDIA to a local landscape
1920x1080 source at least 120 seconds long and CORE0022_DURATION to its
whole-second duration. Run from a macOS shell that permits FFmpeg's
sandbox-exec confinement. The test identifies the active encoder using:

  /bin/ps -axww -o pid=,stat=,command=
  /bin/ps -p "$encoder_pid" -o pid=,stat=,comm=
