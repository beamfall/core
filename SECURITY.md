# Security Policy

## Report a vulnerability privately

Email **security@beamfall.com** with a description, affected component and version or commit, and
reproduction steps or a proof of concept. This is the reachable-today primary route.

GitHub's private **[Report a vulnerability](https://github.com/Beamfall/core/security/advisories/new)**
form is also available. Do not open a public issue or discussion for a
suspected vulnerability.

Report security defects in Beamfall-authored software or Beamfall-operated services. Include the
affected component and version or commit, reproduction steps or a proof of concept, impact, and any
suggested mitigation. Do not use this channel for support, feature requests, ordinary defects with
no security impact, or vulnerabilities solely in third-party infrastructure.

The **release lead** owns intake; the current holder is operator **Russell Lewis**. The administrator
of the affected GitHub repository is the fallback owner. This page records current contact and scope
only. It does not state response deadlines, remediation deadlines, disclosure terms, or legal terms.

## Supported versions

Before the first stable release, reports should identify the current `main` revision or a tagged
pre-release. Published release notes identify any additional supported versions.
