# Trademark policy

Beamfall's source code is licensed under the GNU Affero General Public License v3 (AGPL-3.0), as
stated in [`LICENSE`](LICENSE). **The Beamfall name, logo, and associated brand marks are not**
covered by that license and are governed separately, following the same code/mark split used by
Mozilla (Firefox) and the Rust Foundation.

## What the AGPL license covers

The AGPL grants broad rights to use, modify, and redistribute the Beamfall source code, including
for commercial purposes, subject to the license's copyleft terms (see `LICENSE` §13 for the network
use clause).

## What the AGPL license does not cover

The AGPL does **not** grant any trademark rights. "Beamfall," the Beamfall logo, and Beamfall's
brand marks are trademarks (registration pending — see Status below) and are governed by this
policy, independent of the code license. This mirrors AGPL-3.0 §7(e), which permits a licensor to
require that modified versions carry different names or marks than the original; see the notice in
[`LICENSE`](LICENSE) immediately following the AGPL text.

## Permitted use (unmodified redistribution)

You may use the Beamfall name and logo to refer to **unmodified** builds of the Beamfall server —
for example, "Beamfall" packaged unchanged for a Linux distribution, an unmodified Docker image, or
a hosting provider offering unmodified Beamfall as a service. Referring to the project by its name
in documentation, articles, and comparisons ("nominative use") is always permitted.

## Rebranding required (modified forks)

If you distribute a **modified** version of the Beamfall source — including patched, forked, or
otherwise altered builds — you must not present it as "Beamfall" and must not use the Beamfall name
or logo in a way that implies it is the official project or is endorsed by it. Modified forks must:

- Choose a different name and logo for the distributed product.
- Not use "Beamfall" in the product name, package name, or primary branding.
- Clearly state that the fork is unofficial and unaffiliated with the Beamfall project, if referring
  to Beamfall by name at all (e.g., "based on Beamfall").

## Visual tokens / trade dress (LC-07 interaction)

Beamfall's brand marks (name, logo) are addressed by this policy. Beamfall's broader visual design
system (color tokens, typography, iconography, and other visual assets maintained in the
`beamfall-design-system` repository) is licensed separately from both the AGPL server code and this
trademark policy; see that repository's `LICENSE` for its own terms. **Modified forks that rebrand
per this policy must also not present the unmodified Beamfall visual design system as their own
brand identity** — a rebranded fork should not reuse the full Beamfall look and feel (logo, color
tokens, and trade dress together) in a way that creates confusion about affiliation, even where
individual open-source assets are technically reusable under the design-system repo's license.
Forks may reuse individual open-sourced design tokens under that repo's license terms, but may not
combine them to recreate Beamfall's trade dress as a substitute brand identity.
