# Changelog

All notable changes to the Beamfall Export Format are documented here. Versions
follow Semantic Versioning.

## 1.0.0 - 2026-07-11

- Define the package manifest, media-relative object inventory, and JSON Lines
  record envelope.
- Define the v1 entity-class vocabulary covering portable state required by
  ADR-0168.
- Publish the full-state conformance fixture and the permanent biometric-template
  and device-bound-secret exclusions.
- Require self-contained immutable schemas, canonical package paths and ordering,
  and unambiguous duplicate-key rejection for deterministic imports.
