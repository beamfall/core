# Code of Conduct

## Expected conduct

Project spaces are for constructive technical collaboration. Participants should:

- discuss ideas and work without personal attacks, harassment, threats, or discriminatory abuse;
- respect privacy and avoid publishing another person's private information;
- keep criticism specific to the work;
- stop unwanted contact; and
- use project resources only for their stated purpose.

These rules apply in repositories, issue trackers, review threads, and project-operated community
spaces. They also apply when someone represents the project in a public space.

## Reporting and moderation

Send a conduct report to **conduct@beamfall.com** with links, screenshots, dates, and any other
context available. Do not post sensitive report details publicly. Security vulnerabilities use the
private route in [SECURITY.md](SECURITY.md).

Repository maintainers review reports and may hide or remove content, restrict participation, close
contributions, or block accounts. Decisions may consider severity, repetition, context, and risk to
participants. A maintainer named in a report does not handle that report; the repository
administrator is the fallback reviewer.
