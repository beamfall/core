# Contributing to Beamfall Plugin Repositories

External contributions to this repository are not accepted unless the contributor has a signed Beamfall Contributor License Agreement on file.

Before contributing:

1. Read the Beamfall CLA copied from the core repository as `CLA.md`.
2. Sign the CLA as an individual contributor, or as an authorized entity representative when contributing on behalf of an organization.
3. Send the signed CLA to the Beamfall project operator.
4. Wait for written confirmation that the CLA is accepted.

Do not open a pull request or submit a patch until the signed CLA has been accepted.

This repository must keep `CONTRIBUTING.md` and `CLA.md` linked to each other. Use the propagation checklist in `cla/plugin-propagation-checklist.md` from Beamfall Core when setting up plugin-sdk or plugin-* repositories.
