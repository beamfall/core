# Contributing to Beamfall Core

Beamfall Core's contribution-licensing terms and signature fields are in the existing
[CLA.md](CLA.md). That file is unchanged by this contribution guide and is the only source for those
terms.

Before opening a pull request:

1. Follow the process in [CLA.md](CLA.md) to provide a signed CLA.
2. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
3. Run the focused tests for the changed area.
4. Run `make gate` before submission.

Include tests for behavior changes and keep documentation synchronized with code. Security reports
use the private route in [SECURITY.md](SECURITY.md), not a public issue or pull request.
